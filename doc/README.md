# Documentación

| Carpeta | Contenido |
|---|---|
| `entregables/` | PDF finales: guía paso a paso, requisitos punto a punto, red del laboratorio (memoria de la parte 2), diagramas, memoria de la parte 1 y manual de uso |
| `entregables/src/` | Fuentes Markdown de las memorias, estilos e imágenes |
| `development/enunciado/` | Enunciado de la práctica y plan de numeración del laboratorio 3103 |
| `development/parte1/` | Medidas en bruto de la parte 1 (consumo de la VM) |
| `development/parte2/` | Verificación final de la parte 2 (salidas y capturas de pantalla) y generador del diagrama de construcción |
| `development/historico_script/` | Primera versión automatizada de la parte 2 (sustituida por `parte2/`): su memoria, explicación, pruebas y XML |

Regenerar los PDF después de editar las fuentes:

```bash
doc/build_pdf.sh
```
